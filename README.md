# 花艺布置设计与花材核算系统

浏览器端婚礼/宴会花艺布置设计工具：3D 结构搭建、自动布花、现场灯光预览、精确到朵的花材核算与搭建排程。

## 运行

```bash
npm install
npm run dev    # 开发
npm run build  # 类型检查 + 构建
```

首次打开自动灌入 3 个测试场地、25 个常见花材品种和 1 个示例方案（含拱门/花瀑/路引/主桌花），数据全部存本地 IndexedDB。

## 页面

| 页面 | 功能 |
| --- | --- |
| 场地档案 | 宴会厅建档：层高、吊点网格与单点承重、T台、桌位排布、背景屏 |
| 花材库 | 品种档案：花头直径/枝长/每扎/损耗率，四季价格与到货率，缺货替代建议 |
| 结构搭建 | 拱门/圆环/花柱/花瀑吊架参数化生成，点击骨架段刷花泥，吊顶承重实时报警 |
| 插花编辑 | 主花/配花/叶材配方，按密度自动布花（中心密边缘疏、防穿插），手动拔花/补花，枝长不足提示 |
| 现场预览 | 暖白/冷白/追光灯光，新人站位摆放，机位视角与背景屏遮挡率检测 |
| 花材下单 | 按区域明细，含损耗整扎取整，超预算换花方案对比，搭建排程（吊顶优先），CSV 导出 |

## 关键设计

- **清单与画面一朵不差**：下单页直接聚合场景里实际插着的 `PlacedFlower[]`，布花/拔花/补花都改这同一份数据
- **10 万朵性能**：每品种程序生成 3 个开放度变体几何体（玫瑰/绣球/蝴蝶兰/尤加利等 6 类形态），按 品种×变体 分 `InstancedMesh`、每 4000 朵分块保证视锥剔除生效；实例级朝向扭转 + 颜色抖动破除复制感
- **防穿插**：空间哈希格检查花头最小间距（半径和 × 0.85）
- **承重校验**：骨架自重 + 花泥 + 花材克重，就近 4 个吊点均摊，超单点承重直接报警

## 目录

```

  data/       种子数据（场地/花材/示例方案）

  three/      视口、程序花几何、实例化花场、场地场景、骨架网格
  ui/         六个页面
```
